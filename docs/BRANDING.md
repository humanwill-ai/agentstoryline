# AgentStoryline branding

The owner selected **Sleepy Replicant**, concept 25, on 2026-10-18: a sleepy
robot detective in a fedora and trench coat, holding a coffee cup. This is the
AgentStoryline mascot and logo; TraceForge remains the compatibility name only.

The selected artwork was generated with OpenAI's built-in image generator.
The source PNG is preserved unchanged. The smaller PNGs are resampled exports,
not newly generated interpretations. Keep the white backing so the navy details
remain visible in both light and dark themes.

Assets in `web/assets/`:

- `sleepy-replicant-master.png`: original selected concept.
- `sleepy-replicant-512.png`: square app/profile image and README artwork.
- `sleepy-replicant-128.png`: viewer header artwork (displayed at 48px).
- `sleepy-replicant-32.png`: browser favicon.

Both viewer templates embed the header artwork and favicon as data URLs before
recording content is inserted. Standalone exports need no extra files or remote
requests. Decorative header images use empty alt text beside the product name.
These are raster assets, not vector masters. No trademark clearance is claimed.
